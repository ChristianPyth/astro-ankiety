# Astrologia tradycyjna — ankiety

Statyczna strona informacyjna: klient wybiera rodzaj horoskopu do swojej sprawy, wypełnia
ankietę i zapisuje odpowiedzi jako plik tekstowy, który wysyła astrologowi na Discordzie.
Strona niczego nie wysyła ani nie zapisuje na serwerze; szkic odpowiedzi zostaje tylko
w przeglądarce klienta.

A static information page: clients choose the kind of chart for their question, fill in a form
and save the answers as a text file to send to the astrologer on Discord. Nothing is sent or
stored on a server.

Jeden plik: `index.html`. Wersja angielska: dopisz `#en` do adresu.
